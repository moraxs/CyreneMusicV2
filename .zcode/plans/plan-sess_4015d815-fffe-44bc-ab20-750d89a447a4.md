## 目标

将 **SuperCyrene 播放器**左下角控制面板里的「歌曲列表」按钮（当前点击弹出 Miuix 底部底板 `QueueSheet`）改为进入一个**全新的全屏「展览馆」页面**，复刻 folia-major 前端项目 `GridView.tsx` 歌单详情页的经典蜂窝/拍立得卡片效果。

改动范围限定在 SuperCyrene（桌面端），经典桌面播放器与移动端播放器保持原样。

## 新增文件

### 1. `lib/features/player/super_cyrene/super_cyrene_hex_grid.dart`
纯 Dart 数学工具（便于单测），从 `GridView.tsx` 的 `hexViewport.ts` + `hexCardTransform.ts` 移植：
- `_HexCubeCoord`（x,y,z）与 `getHexCubicAtIndex(int index)`：返回中心外扩的六边形螺旋坐标（复用 `GridView.tsx` 的 `getHexCubicAtIndex`）。
- `buildHexGridCoords(count, spacingX, spacingY)` → `List<HexGridCoord>`，其中 `baseX = cube.x*spacingX + cube.z*spacingX/2`、`baseY = cube.z*spacingY`。
- `computeHexCardFrame(coord, dx, dy, options)` → scale/opacity/zIndex/playOpacity/playScale/queueOpacity，公式完全照搬：
  - `progress = distance / maxDistance`（clamp 到 0..1）
  - `scale = 1.1 - 0.65*progress`
  - `opacity = 1.0 - 0.60*progress`
  - `zIndex = 50 - 49*progress`
  - 播放按钮：`distance < 40` 时 `playOpacity = 1 - distance/40`、`playScale = 1 - 0.2*distance/40`
  - 队列按钮 `lodStart~lodEnd` 区间淡出
- 断点布局配置（按视口宽度选一组），照搬参考值：
  - `<768`：card 180×280 / spacing 205×270 / maxDistance 420
  - `<1440`：card 220×330 / spacing 250×320 / maxDistance 500
  - `<2000`：card 250×375 / spacing 285×365 / maxDistance 580
  - `>=2000`：card 280×420 / spacing 320×410 / maxDistance 660

### 2. `lib/features/player/super_cyrene/super_cyrene_song_gallery.dart`
全屏展览馆页面（StatefulWidget，直接复用 `DesktopFullscreenPlayerRoute` 的底部上展开路由进场）。结构（对照 `GridView.tsx` 布局）：

- **背景**：当前/队列首曲封面 `CachedNetworkImageProvider`，全屏 `BackdropFilter(blur(30))` + `scale(1.1)` + 低透明度（深色 ~0.12），再叠一层 `0x26000000` 深色（与 SuperCyrene 播放器一致）。
- **顶部左返回按钮**：毛玻璃圆钮，关闭页面。
- **顶部居中标题胶囊**（毛玻璃）：显示「播放队列 · N 首歌曲」；点击切换左侧 Cut-in 信息面板。
- **中央蜂窝画布**：`Stack` + `Positioned` 渲染蜂巢卡片场。用 `GestureDetector` 处理拖拽平移（`Offset _pan`），滚轮同样映射到平移；`AnimationController` + spring 做惯性/回弹。根据每个卡片的 `computeHexCardFrame`（含距中心距离）应用 scale/opacity/zIndex，并做视口 culling（只构建可见卡片，参照 `clipRadius`）。
- **拍立得卡片** `_PolaroidCard`：方形封面（用 `CachedNetworkImage` + `imageHeaders` + `coverDecodeWidth` 降采样，缓存复用）+ 底部标题（歌名）、歌手、专辑、时长、两位序号；居中卡片上显示播放按钮；入场动画（fade + scale + 轻微 rotateY，用 `Transform`+`Matrix4` 实现类 3D 翻转）。
- **交互**：点击卡片 → 居中该卡；点击居中卡上的播放按钮 → `playback.playTrack(track, queue: state.queue)`；方向键移动焦点（移植键盘导航逻辑）。
- **Cut-in 信息面板**（左侧玻璃面板，`backdrop-blur`）：当前高亮歌曲封面 + 歌名 + 歌手·专辑 + 时长，按钮区：播放全部（从头播队列）、加入队列已含、清空队列、关闭。
- **右侧曲目列表侧滑面板**（玻璃面板，虚拟化 `ListView`）：逐行 40px 封面缩略图 + 歌名 + 歌手，高亮当前曲，点击播放，hover 显示移除按钮（`playback.removeFromQueue`）；滚动定位到当前曲。由右下角「列表」浮钮切换。
- **右下角浮动按钮**：打开侧滑列表。
- **Escape 关闭**（`CallbackShortcuts`，与播放器一致）。

### 3. 入口改动
`lib/features/player/super_cyrene/super_cyrene_control_panel.dart` 行 146：
```dart
onQueue: () => QueueSheet.show(context, widget.playback),
```
改为：
```dart
onQueue: () => Navigator.of(context, rootNavigator: true)
    .push(DesktopFullscreenPlayerRoute(
      builder: (_) => SuperCyreneSongGallery(
        playback: widget.playback,
        account: widget.account,
      ),
    )),
```
新增 import：`desktop_fullscreen_player_route.dart`、`super_cyrene_song_gallery.dart`。`QueueSheet` 保留（经典播放器仍用），但移除该文件的 QueueSheet import。
